# DiscManager (в разработке)
<img width="1283" height="700" alt="image" src="https://github.com/user-attachments/assets/c28882b0-826a-41a3-ae8f-0af723b4674b" />


* #### Плагин добавляет простой интерфейс для управления проигрывателем (Jukebox) через GUI.

---

## ❗Зависимость

* [CustomDiscs-SVC 2.5.0](https://modrinth.com/plugin/customdiscs-svc/version/2.5.0)
* И все зависимости CustomDiscs-SVC (Simple Voice Chat, Command API, PacketEvents)
* Я делал на CustomDiscs-SVC 2.5.0, но если у вас получится запустить и на новых версиях, пишите

---

## 📦 Возможности

* Открытие меню проигрывателя через предмет (Blaze Rod)
* Список пластинок с разбивкой по страницам
* Воспроизведение через GUI (без ручной вставки)
* Добавление пластинок (Shift + ЛКМ)
* Удаление пластинок с авто-перестроением списка
* Поддержка кастомных пластинок
* Базовая защита от дюпов

## 🎮 Как пользоваться

### 1. Открыть меню

* Возьми **стержень (Blaze Rod)**
* ЛКМ по проигрывателю

---

### 2. Воспроизвести музыку

* Нажми на любую пластинку в меню
* Она автоматически вставится в проигрыватель

---

### 3. Остановить музыку

* ПКМ по проигрывателю **с пустой рукой или любым предметом (кроме пластинки)**

---

### 4. Добавить пластинки

1. Нажми кнопку **«Добавить»** (внизу по центру)
2. Откроется новое меню
3. В своём инвентаре:

   * нажимай **Shift + ЛКМ по пластинкам**
4. Они добавятся в список

---

### 5. Удалить пластинки

1. Нажми кнопку **«Удаление»**
2. Меню станет красным (режим удаления)
3. Нажми на пластинку → она удалится
4. Выйти из режима — кнопка по центру снизу

## 🧭 Интерфейс

### Главное меню
<img width="351" height="504" alt="image" src="https://github.com/user-attachments/assets/72c034fc-481f-4275-8fac-c76e3619df5a" />



* **Центр (большое поле)** — список пластинок
* **Стрелка слева (⬅)** — предыдущая страница
* **Стрелка справа (➡)** — следующая страница
* **Барьер** — включить режим удаления
* **Зелёная кнопка** — добавить пластинки

---

### Меню добавления
<img width="352" height="297" alt="image" src="https://github.com/user-attachments/assets/3d313cfe-76d6-4ab7-99a1-774780043c3d" />

* **Лист бумаги** — подсказка
* **Стрелка** — вернуться назад
* Всё остальное — твой инвентарь

---

### Режим удаления
<img width="352" height="498" alt="image" src="https://github.com/user-attachments/assets/373e7203-c2ba-4df9-a191-9a1e0259e1e3" />

* Нижняя панель становится красной
* Кнопки:

  * центр — выйти из удаления
  * стрелки — переключение страниц
